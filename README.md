# Patent & Trademark Skills

Agent Skills that help you organize patent and trademark filings in Canada and the United States.

| Skill | What it helps with |
| --- | --- |
| `canada-patent` | Organizing a patent application with CIPO |
| `canada-trademark` | Organizing a Canadian trademark application with CIPO |
| `us-provisional-patent` | Organizing a US provisional patent application with the USPTO |
| `us-trademark` | Organizing a US trademark application with the USPTO |

These are preparation guidelines, not legal advice. Review every filing with a registered patent or trademark agent before you submit it.

## Install

With [Dojo Workspace](https://heydojo.ai):

```bash
dojo skills add neekware/patent-trademark-skills
```

Or with the [`skills`](https://github.com/vercel-labs/skills) CLI, for any agent that reads `~/.agents/skills`:

```bash
npx skills add neekware/patent-trademark-skills -g
```

Add `-p` to `dojo skills add` (or drop `-g` from `npx skills add`) to install into the current project only.
